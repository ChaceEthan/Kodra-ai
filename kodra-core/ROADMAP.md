# Kodra AI - Product & Capabilities Roadmap

This document outlines the multi-phase evolution strategy for **Kodra AI**, moving from a transparent educational PyTorch core to a production-grade coding assistant and autonomous developer agent.

---

## Roadmap Phases

### Phase 1: Kodra Core (Current)
- [x] Causal GPT PyTorch Architecture (~4.83M params)
- [x] Modular Tokenizer & Data Loader
- [x] AdamW + Cosine Annealing Trainer
- [x] Autoregressive Code Generator
- [x] Interactive Dashboard & Visualizers
- [x] Comprehensive Unit Test Suite

### Phase 2: Kodra Agent (Future)
- [ ] Multi-file Workspace Context Window
- [ ] Tool Execution Engine (Shell, Git, Linter)
- [ ] Autonomous Planning & Reasoning Loops
- [ ] Fast API & WebSocket Agent Protocol

### Phase 3: Kodra for VS Code (Future)
- [ ] Native VS Code Extension
- [ ] Ghost-text Inline Code Completion
- [ ] Sidebar Chat Interface
- [ ] Local & Remote Model Endpoint Sync

*Note: Kodra Agent and Kodra for VS Code names are reserved for roadmap planning.*
